## Reproduction and limits

Read pg_policies for qual/with_check containing auth. or current_setting(. Match the exact 69 policy identities below against get_advisors(type=performance), filtering name=auth_rls_initplan. A regex is a discovery lead, not a SQL parser; future nested/wrapped/indirect helper usage must be assessed structurally, not blindly replaced. Capture all policies on each affected table, including unflagged overlapping ones, before implementing.

Catalog query:

```sql
select schemaname, tablename, policyname, cmd, roles, permissive,
  md5(coalesce(qual,'') || '|' || coalesce(with_check,'')) as expression_fingerprint
from pg_policies
where coalesce(qual,'') ~ '(auth\\.|current_setting\\()'
   or coalesce(with_check,'') ~ '(auth\\.|current_setting\\()'
order by schemaname, tablename, policyname;
```

Fingerprint is an MD5 drift marker, not a security signature. Separately compare cmd, roles, permissive, table RLS flags and grants. Capture exact definitions privately at implementation time; published baseline intentionally omits JWT email allowlist literals.

begin read only;

select count(*) filter(where public.has_role(auth.uid(),'admin'::public.app_role))

Variants: replace only the filter expression with `public.has_role((select auth.uid()),'admin'::public.app_role)`, then `(select public.has_role(auth.uid(),'admin'::public.app_role))`. Verify context_set=true separately; do not infer it from timing output. This was verified during the investigation with authenticated_context=true and matching allow counts.

## Helper findings

Live public.has_role(uuid, public.app_role) is STABLE SECURITY DEFINER, search_path public, reading public.user_roles by user_id and role. Live public.has_app_access(uuid, public.app_name) is STABLE SECURITY DEFINER, search_path public, reading public.app_access by user_id and app. Live app.has_role(app.app_role) and app.has_any_role(app.app_role[]) are STABLE SECURITY DEFINER; the former combines app.user_role/app.role membership with app.jwt_role_names(), the latter delegates to app.has_role. These are distinct role systems and enum types. No helper definition was modified. Complete transitive dependency qualification for packaging remains an implementation gate.
