## 7. Lessons that cost time

- CI "green" on a draft with only warnings ≠ the migration applies; the
  replay warnings are load-bearing — a contract test makes them fatal.
- `pg_get_function_identity_arguments` never renders typmod and renders
  schema-qualified only when the schema is off the search_path.
- ON CONFLICT SET must use the insert alias; schema-qualified target refs are
  a parse error at runtime (plpgsql defers it past CI static checks).
- `scripts/test_production_catalog_verification.py` is CRLF: never rewrite it
  with text-mode python (whole-file diff); edit bytes.
- Edits to `production_catalog_verification.py` require re-recording the
  detector hash in `docs/verification/throughput-guard-truth-baseline-20260828.json`.
- Rapid force-pushes leave stale queued check suites; check
  `/commits/<sha>/check-runs` (API), not `gh pr checks`, for the truth.
