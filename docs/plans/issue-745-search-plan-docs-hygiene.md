## 1. The ultimate goal

Plans in this repository are executed by fresh AI sessions that read only the file. A plan that still tells them to do superseded work, points at files that no longer exist, or publishes licensed character names in this **public** repository causes wrong builds and licensing exposure. When this plan is done, the search plans say only what is currently true, contain no licensed names beyond what the repository already exposed before #1037, keep product screenshots off public pages, and their acceptance checklist matches their own acceptance text.

**If a step conflicts with this goal, the goal wins: stop and flag it.**
